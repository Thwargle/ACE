# Release v82 check-in notes

```text
Release v82: improve desktop/VR networking, collision, panels, and updating

- Synchronize Windows, PC VR, Quest, and installer version to 2026.09.27.82.
- Let desktop clients receive VR head, hand, body, and equipment poses.
- Keep ordinary movement/animation broadcasts compatible across client modes.
- Separate remote locomotion from network correction and suppress tiny drift.
- Constrain prediction to slopes, walls, and supported cliff edges.
- Pair VR poses with current feet positions and retain history across equipment swaps.
- Preserve newer position corrections and resume normal movement after tracking loss.
- Use authored creature collision spheres instead of oversized model bounds.
- Improve wall sliding, stair contacts, and bounded embedded-position recovery.
- Remove generated scenery from building-occupied cells and invalidate old caches.
- Recover stale door/NPC interactions and validate pending VR landings before actions.
- Preserve zoom distance when changing overhead camera angle.
- Simplify VR fellowship vitals and organize VR settings into consistent sections.
- Add mipmapped, trilinear-filtered VR HUD panels while keeping World anchors fixed.
- Add optional automatic updates, disabled by default, with cancellable closing notices.
- Publish verified installers, Quest packages, release notes, and updater metadata.
```

The companion ACE server changes are included in this check-in. They enable
receive-only pose subscriptions for desktop observers and fix queued landing/root
ordering and stationary interaction completion. Other hosts must deploy these
server changes to gain those features. Original retail executables continue to
receive ordinary movement, but cannot render the custom tracked-hand extension.
