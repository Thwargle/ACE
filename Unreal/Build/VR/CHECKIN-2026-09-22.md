# Release 62 check-in

Changes since `080f152e` (public release 60). Suggested commit message:

```text
Fix portal memory growth and improve performance, collision, and retail UI

- Retire old scene resources before portal destination allocations
- Evict departed meshes and reject cancelled or stale streaming results
- Bound dungeon workers and remove redundant environment-data copies
- Cache UI name lookups and unchanged visibility state
- Accelerate lossless terrain mip compression and persist prepared mip chains
- Remove unnecessary mipmaps from native UI chrome
- Improve multi-surface collision recovery at corners and the Shoushi lifestone
- Restore retail minimap markers, click selection, and DAT direction arrows
- Keep Apply accessible after desktop UI scaling
- Shorten VR enemy health bars and hide zero-health/one-shot meters
- Add streaming, rendering, UI lifetime, radar, and collision regressions
- Release Windows 2026.09.22.68 and Quest 2026.09.22.quest.62
```

## Validation

- Windows and Android packaging succeeded. Six packaged Windows suites passed:
  LoadingTransition, PortalResourceRetirement, RadarArt, ShoushiGap, UIScreens,
  and VR RigAndMenus.
- Development regressions also passed for StreamingRetirement, AcademyCorners,
  InteriorStreaming, LandscapeTextureFidelity, TerrainCompression, TextureBudget,
  and InputLifecycle.
- Quest 3 completed one login and seven portal transitions; the user confirmed
  repeated Obsidian Rim visits worked. Sampled peak total PSS was 2.67 GiB versus
  5.26 GiB in the failing v61 recording, with negligible swap. Outdoor performance
  remained about 59–66 FPS; this does not establish the 90 FPS target.
- Public bundles exclude saved accounts, server configuration, DAT files, SDKs,
  and diagnostic output. Release files are verified with SHA-256.
- v62 is published on both website landing pages. All three complete public
  downloads, pages, metadata, and release documents matched staging over HTTPS.

Generated builds, cleanup inventories, capture evidence, and deployment reports
remain in ignored directories. Source changes have not been committed automatically.
