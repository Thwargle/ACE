## Scope

Layout files save window geometry, with automatic snapshots separated by
character, server, display size, and desktop/VR mode. Existing settings and
keymaps are retained. Spell-tab memory lasts until logout, including across
portal transitions.

Restricted door checks use `ItemUseable`, not display text. The client rejects
direct use and honors live property updates. ACE server source adds the same
guard before and after approach; server owners must deploy that source change
for the additional enforcement. Keys, switches, scripts, locks, and quest
requirements retain their existing activation paths.
