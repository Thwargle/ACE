# Release 67 check-in

Changes since `3bdef7d0` (release 66). Suggested commit message:

```text
Restore retail window cursors and resizable shortcut rows; release v67

- Use original retail move and directional resize cursor artwork and hotspots
- Keep the active cursor during dragging and respect the UI lock
- Resize the shortcut toolbar between one and two rows using its bottom border
- Preserve the toolbar's top position and retail width/height limits
- Clip partially revealed shortcut rows without stretching their icons
- Prevent hidden shortcut slots from intercepting world clicks
- Restore saved toolbar height without overwriting window geometry on load
- Cache cursor widgets and avoid redundant shortcut-panel visibility changes
- Add regression coverage for resizing, capture, locking, clipping, and persistence
- Release Windows 2026.09.23.73 and Quest 2026.09.23.quest.67
```

## Behavior

The cursor textures and hotspots come from the original retail Dragbar and
Resizebar data. Pointer queries follow the same handles used to initiate movement
or resizing, including captured drags outside the original handle.

The toolbar uses retail's fixed 310-pixel width and 100-132-pixel height range.
Unlock the UI and drag the bottom border upward for one row or downward for two.
The top edge stays fixed. Both rows retain their shortcuts and key bindings;
concealed slots cannot consume mouse or controller selection. The shared UI code
applies to desktop, PC VR, and native Quest.

Loading saved geometry no longer calls the lock setter that writes current
defaults back to the same settings file before reading the saved dimensions.
