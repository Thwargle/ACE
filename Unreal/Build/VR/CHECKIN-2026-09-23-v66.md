## Implementation details

The stair fix uses actual cell bounds and the predicted player position, keeping
collision and static props available through the full vertical extent of a
building. It replaces the former fixed-height exclusion; there are no Fort Teth
location exceptions. Interior section splitting also preserves the authored
texture wrapping flag, retaining tiled architecture and foliage clamping.

Equipment swaps wait for authoritative container and wield acknowledgements,
handle delayed or rejected operations, and preserve the player's requested combat
state. Corpse contents can precede item creation without losing container identity;
nested loot and recall cleanup use the same ownership rules.

The keybind interface uses retail DAT buttons, tabs, and file dialogs. Keymap
import/export preserves supported modifier and mouse bindings and retains unknown
entries for subsequent saves. Existing custom settings are retained. Native art
and generated text share window paint ordering so dialogs cover the controls below
them. Main-player vital meters clip their children to native bounds without
changing the texture artwork.

Windows cooking also regenerated the tracked runtime material assets. Those assets
were synchronized into the Quest project before its build so both packages use the
same generated materials.
