# Release 65 check-in

Changes since `2d2bfcf3` (public release 64). Suggested commit message:

```text
Fix foliage texture edges and clarify login errors; release v65

- Match retail texture clamping to remove dark lines around tree edges
- Preserve explicitly repeating textures and separate their cached samplers
- Carry texture addressing through scenery, buildings, interiors, and disk caches
- Explain ACE/GDLE login failures with actionable messages and original error codes
- Test real foliage textures, rejection packets, and responsive error layouts
- Release Windows 2026.09.22.71 and Quest 2026.09.22.quest.65
```

Retail's object rendering uses clamped addressing unless a polygon's stippling
flag requests wrapping. Previously all world surfaces wrapped, allowing opaque
texels from the opposite edge to leak into transparent tree borders. The shared
renderer now preserves the authored choice for each polygon side and material.
Texture dimensions, mipmaps, and the existing alpha threshold are unchanged.
The interior tile-cache schema advances to 16 to preserve the new section flag.

Login rejection handling now distinguishes accounts already online, full servers,
invalid login methods, missing accounts, and character loading/saving failures.
It handles both numeric ACE CharacterError codes and GDLE's separate StringInfo
codes. Unknown errors remain explicitly unknown. Codes and server-supplied boot
messages are retained for diagnosis; no protocol/state-machine changes are made.
