# September 26 client regression review

## Implemented

- Autorun now survives release of the forward key held when it was enabled. A new forward/backward command or another autorun press cancels it.
- Retail static labels clip against window paint coordinates. They previously used desktop tick coordinates, which hid tabs, button captions, and vital text when the game window moved away from the desktop origin.
- Spell-bar maximum width follows the actual viewport in UI layout units instead of the retail layout's fixed 800-unit canvas. Width changes remain pixel-granular.
- Key capture ignores releases without a matching press during that capture. This prevents synthetic/orphan modifier releases from completing a binding. Left/right Shift, Control, and Alt are explicitly labeled. The filter only runs while a selector is capturing.
- Character selection cancels launcher retry timers. Deferred launcher callbacks cannot cover character selection, creation, or an active world session.
- Vendor split defaults follow retail's item-type mask: consumables and trade notes begin at one; ammunition selects the available stack. Explicitly adjusted quantities survive selection refresh and reach the cart.
- Vendor item captions use the singular item name. The toolbar describes the stock independently of the split quantity and now uses the server-authored plural name, which the public-description decoder previously discarded.
- Trade notes cost face value plus 15% and sell at face value, independently of ordinary vendor rates. Pricing divides stack value into integer unit value before applying quantity/rate, as retail does.
- Remote object initialization no longer applies descriptor velocity a second time after the position's grounded flag has resolved it. Grounded velocity-bearing spawns follow the floor; actual airborne velocity and projectile paths are retained.
- Lower-sphere support classifies a stair/ramp's authored floor plane rather than losing support at convex edges because the sphere separation normal points sideways. Ascending a flat tread's steep riser still requires the complete step/headroom checks. This reproduced and resolved the higher center-post trap at C6A901AE without breaking outdoor bench traversal.

## Limits and follow-up

- The center-post trap was reproduced before the support fix and passes afterward.
- The reported solid-wall clipping did not reproduce in the expanded geometry tests. Fast runners did cross the mathematical continuation of walls at openings or beyond stair rails; independent traces confirmed those crossings contained no solid face. That is not evidence that every live clipping case is resolved.
- The network velocity fix has automated regression coverage; the reported live running-animation video was not visually validated. Confirm downhill running and animation against another live client after rebuilding/restarting the preview.
- Keypad action tests pass, but the user's hardware-specific keypad failure remains unconfirmed. The modifier capture fix requires a live keyboard retest too.
- These changes have not been published to the website or installed on a headset in this task.

## Overhead camera follow-up

The sky camera was using the ordinary orbit pitch limits while retaining its 450-unit arm and disabled roof collision. Lowering the view could therefore swing the camera below the world.

- Mouse and keyboard now share mode-aware orbit handling. Retail `CameraSet::Raise/Lower` retain the downward direction and translate the overhead camera instead of pitching it. Translation is normalized to the client's input delta, with the existing minimum camera distance preventing it from crossing the player.
- Retail `CameraSet::Rotate` exits look-down/map mode before rotating. Horizontal and diagonal input now restore the saved normal distance and collision before changing angle. Wheel zoom continues to exit overhead mode.
- Windows editor rebuild passed: `Unreal/Saved/Logs/sep26-overhead-editor-build.log`.
- `ACE.RetailParity.CameraAndEdges` and `ACE.RetailParity.WorldEntry` passed: `Unreal/Saved/ReleaseValidation/sep26-overhead/Report`. Coverage includes actual camera socket positions during 50-second keypad holds at 30/90 FPS, extreme/inverted mouse deltas in both overhead modes, horizontal and diagonal transitions, wheel zoom, and restoration of the saved normal view. WorldEntry also covers physical keypad routing and map-mode toggling.
