# Release v81 check-in notes

```text
Release v81: improve camera parity, remote movement, collision, and appraisal

- Synchronize Windows, PC VR, Quest, and installer version to 2026.09.26.81.
- Preview FOV live and use retail's degree range and aspect conversion.
- Correct zoom timing, bounds, first-person behavior, and distance blending.
- Preserve configured FOV through portal space and world reveal.
- Improve remote ground following, slope direction, motion speed, and scale.
- Keep supported creatures grounded through horizontal network updates.
- Sweep ordinary position corrections against walls and other solids.
- Refine stair-edge support and bounded descent recovery after side contacts.
- Retain solid-object collision independently of camera/room visibility.
- Keep moving objects visible across stale network cell boundaries.
- Support charging the next jump while airborne without a midair impulse.
- Prevent repeated world-model selection from amplifying weapon glow effects.
- Show mana charge/stone capacity, efficiency, and destruction properties.
- Disable Apply/Reset when an options page has no pending changes.
- Correct the packaged interior test fixture's game-world binding.
- Refresh release downloads, updater metadata, and public release notes.
- Preserve the Quest updater's legacy version-format compatibility while
  keeping installed Windows and Quest versions synchronized.
```
