AC:VR, on your Quest.

This Windows installer folder contains the native Quest app and tools to copy your game data. Extract the entire ZIP before running any installer.

Before you install

  1. Prepare your updated retail DAT files. Required: client_portal.dat, client_cell_1.dat, client_local_English.dat. Keep client_highres.dat alongside them if available. Retail downloads and update guide.
  2. Enable Developer Mode using Meta’s device setup guide.
  3. Download Android platform-tools for Windows. Extract its platform-tools folder into this installer folder.
  4. Connect a USB data cable, wear the headset, and accept Allow USB debugging. Choose Always allow from this computer.

Install, then step into Dereth

In File Explorer, double-click Install-Quest.cmd. Provide your DAT folder when asked. Keep the headset awake and connected until every file verifies and installation finishes. On the headset, open AC:VR from Apps → Unknown Sources, choose a server and account, then Launch.

For an existing installation, use Update-Quest.cmd. To check or repair game data, use Repair-Quest.cmd. Updating preserves your data and settings; do not uninstall first.

Need a hand?

See README.txt for offline instructions, release notes, or the complete online setup guide. If USB drops out, try a different data cable and a direct PC USB port.

No retail DAT files, server, or saved player accounts are included. Full VR combat and player motion require a VR-enabled ACE server.
