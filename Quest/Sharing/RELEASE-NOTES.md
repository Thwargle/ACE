# AC:Unreal / AC:VR v168

Windows, PC VR, Linux, Quest and the Android preview share version **2026.11.27.168**.

- Import your AC2 Legions DAT in Graphics Options to choose the sky, ground textures, grass textures, interactive grass, trees and boulder textures independently. Reimport an older selection to unlock the new artwork. Grass grows in patches and bends underfoot. Replacement trees fit the original scenery, including rooftop planters.
- Water covers submerged models while allowing you to select creatures for combat and fishing holes for fishing.
- Remote players and creatures have updated movement and facing. VR pose updates also handle transitions between tracked and standard animation.
- Default and imported retail keymaps support creature cycling, previous selection, Help, Plugin Manager and alternate camera controls. Click **Apply** in Options to refresh the interface in game.
- Quest installer revision 14 accepts the newer desktop Legions artwork caches. Use Install-AC2-Sky.cmd to transfer your cache or your Legions portal.dat to the headset.
- Server admins can update to this ACE server build and run `@modifybool quest_lookup_enabled true`. Players can then use `/myquest <questflag>` with the exact internal flag to check their own completion. The lookup defaults to off and has its own setting independent of the full `/myquests` list.
