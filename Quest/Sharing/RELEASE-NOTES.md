# AC:Unreal / AC:VR release 115

Windows desktop, PC VR, native Linux x86_64, and standalone Quest share version
**2026.10.14.115**. Android version code: 115. Quest installer revision: 9.

## Character-selection hotfix

- Restore the character-selection background and controls on large, ultrawide,
  and tall displays, including the screen used to select a character and play.
- Keep the centered native layout visible when resizing the window. The screen's
  ownership container no longer incorrectly clips its artwork and controls.
- Preserve clipping within actual windows, including housing controls.
- Add rendered regression checks across ten viewport sizes and resize sequences.

## Installation

- **AC-WoW Transmog, its provider, converter and model assets are excluded.**
- Updates preserve accounts, settings, profiles and DAT files. Linux updates
  are downloaded and extracted manually. Game DAT files and a server are not
  included.
